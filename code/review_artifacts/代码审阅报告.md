# greenbook阶段A代码审阅

日期：2026-11-16。只审阅和建立隔离反例，没有修改greenbook源码或原实例。

当前新增主体是greenbook的2027—2029两地区玩具模型，输入明确标注scenario。它不是2026—2040实际数据模型。此范围本身不算代码错误。

原9项结构测试通过。直接运行测试遇到系统临时目录权限问题后，仅将tempfile.mkdtemp替换为工作区隔离测试目录重新运行，没有改断言。通过只能覆盖当前固定玩具输入，以下反例均不在现有测试覆盖内。

## 确认问题

1. **[P1] HBI等跨节点投入品运费没有进入优化目标。** `greenbook/model/solve.py:110–114`只累加cost_transport[qi]，未累加c[qi]，而钢材运输在123–124行正确更新两者。因而模型免费运输HBI，报告却照计运费。隔离反例把HBI-EAF的非资源运营成本设为-10000以保证该路径被使用（纯测试，不是实证参数）；产生12.761905Mt HBI-EAF产量。将HBI运费从25提高至1000000 €/t后，产量和目标值均完全不变，目标仍-23858.566621M€，报告分项合计却12187015.745546M€。应把该费用同步加入目标，增加目标与各成本分项之和一致的断言，以及运费变化响应测试。

2. **[P1] 缺失资源行会使投入成为免费且无限的资源。** `greenbook/model/solve.py:196–212`仅遍历case.resources出现的键，而非所有配方投入所需的键。删除全部pellets供给行后，对应投入没有任何平衡约束，模型仍optimal；N目标从91316.470006降为55147.952457M€。应先校验每项外生投入必有同节点同年供给块，或对所有需求资源建平衡，缺供给时将其可用量限制为0；中间品必须另走完整产出消费平衡，不能同缺失资源混淆。

3. **[P1] 同一选项的多个投资年份被静默丢弃。** `greenbook/data_model.py:99–101`使用option_id为唯一键，并用setdefault保留第一条；`build_dynamic.py:48–60`及求解器亦每选项仅有一个决策年份。在2027年的INV_EU_DRI后增加同选项2028行，CSV有4条记录，加载后仍3个选项，只保留2027。当前玩具仅决策2027所以未暴露，但扩展2026—2040会丢掉后续14年决策。应按(option_id,decision_year)建立投资批次，所有变量、产能叠加、限建、付款与残值同步更新；若option_id本身设计为批次唯一ID，则加载时必须拒绝重复ID，不能悄悄忽略。

4. **[P1] 钢种和需求情景索引没有进入供需匹配。** `greenbook/model/solve.py:177–183`对每条(region,grade,demand_case,year)需求，都使用该地区所有钢配方同一组交付变量。新增SECOND_GRADE并赋与原钢种相同需求后，目标和产量完全不变，一批钢同时被用于满足两条需求；不同需求量则会形成相互冲突的等式。应按grade筛配方/定义兼容矩阵，并在求解前只选择一个demand_case，或扩展情景维度；增加两钢种需求合计检查。

5. **[P2] 未投运项目残值可以超过CAPEX。** `greenbook/model/build_dynamic.py:73–78`允许years_used为负，remaining可能大于life。直接输入2027决策、10年建设期、20年寿命、CAPEX100、2029期末，残值为135。该错误会让未来才投运的项目获得超额退款，扭曲期末投资。应区分在建资产和已投运资产的终端估值；至少不能用负运行年龄让已投运残值公式超过原资本成本，终端折现时点也须一致。现有实例2年建设期没有触发这一边界。

6. **[P2] 证书交付规则的年份被最后一行覆盖。** `greenbook/model/build_certificate.py:27–30`循环所有年份，但只存一个eu_rule；`attribute_use`也不接收年份。若2027排除EU交付、2029允许，最后年份将覆盖2027规则，导致历史不合资格交付被签发。应将eu_use_rule保存为year->rule，并从solve.py:282传入t；同样要显式筛选rule_case，避免多规则互相覆盖。当前玩具每年同规则，所以9项测试不会发现。

## 另一个导出错误

`greenbook/analysis/compare.py:85–90`把三年折现CBAM/原产地碳税合计写在第一年的year行，后两年写0，同时证书转移是逐年未折现值。该表不可作年度支出比较。建议分开年度未折现现金流与全期折现合计，名称和单位明确标识。

## 适用边界

初始资产退役/start_year/scope_share尚未进入约束，现有说明已披露未启用提前退出；不能将当前恒定初始能力直接当作2026—2040资产寿命路径。source中的年度scenario_params同样忽略year（data_model.py:104–107），未来年度碳价输入会覆盖为一条常数，应随多期投资接口一起改造。

关键反例数值保存在targeted_evidence.json；duplicate_investment_fixture为隔离生成的玩具数据，非采集或校准数据。所有货币影响仅是代码反例，不代表真实政策效果。
