# 阶段A最小实例：数据合同

本目录是 `make_instance.py` 写出的**玩具数据**（`value_status=scenario`，`source_id=TOY_STAGE_A`），
对应《详细模型建模方案与数据需求》§17.2 的**阶段A结构编码**：

- 字段名对齐 `output/模型设计与数据清单/实施版数据模板`（04/07/10/11/12/13/16/17/18/19/21/25 共12张表）；
- 两地区（EU、X）、8个配方（含1个HBI中间活动）、3个共享能力池、11个资源供给块、4个入境责任类别；
- 2027—2029三个年度，投资决策2027年、建设期2年、2029年投产；
- 所有数值只用于结构检查（§17.3），**不是采集值、校准值或政策结论**。

与完整实施版的差异（已在代码中记录、待后续阶段补齐）：

- 能源与制氢模块（模块A）用外生供给块近似，未联立逐小时工程问题；
- 排放的资格/责任账只含工序分量（`boundary_version=STAGE_A_PROC_ONLY`）；
- 未启用提前退出、改造、库存、跨年银行和弹性需求；
- 关税、从价税和小额豁免未建模。
