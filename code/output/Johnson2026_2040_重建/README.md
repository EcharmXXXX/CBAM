# 2026—2040年重新初始化：数据准备与口径

本目录对应用户最新选择：2026—2040年，使用2026实际状态重新初始化，保留BF-BOF、SCRAP-EAF、H2-DRI-EAF三条路线，并明确记录未覆盖产能。

**当前完成的是日历与数据准备，不是已校准、已求解的2026—2040模型。** 2022—2035修正版及其45项测试结果保持原样，不能作为这个新基线已经通过验证的证据。

## 已确定的时间口径

| 内容 | 设定 |
|---|---|
| 生产、贸易和排放模拟 | 2026—2040，共15个年度 |
| 新投资决策 | 2026—2040 |
| 建设期 | 沿用3年 |
| 2026年首次新决策投运 | 2029年 |
| 2040年末次决策投运 | 2043年 |
| 前瞻参数覆盖要求 | 2026—2043，共18年 |
| 初始在建项目 | 独立核实2026年前已承诺、2026年及以后投运的项目，尤其2026—2028的既有管线 |
| 初始化方式 | 采用外部实际状态，不承接2022模型推算的2025年末状态 |

完整年度模型暂按2026-01-01作为期初。已下载的GEM数据是2026年9月快照，尚不能直接充当1月1日期初：需要逐设施核实年内投运、退役和扩建，或明确采用年内快照近似。该近似尚未作为实际期初输入采用。

上轮“2022—2024年不退役”的处理只适用于旧基线，不自动变成新基线“2026—2028年不退役”。新模型需要按现有设施年龄、检修和已公告退役安排构造库存路径。

## 已实际取得的原始资料

- GEM《Global Iron and Steel Tracker》2026年9月V1：按国家、钢生产方法列示的运行容量，已下载CSV并解析79个钢产能国家记录。
- GEM同版按还原剂分类的运行DRI容量，已下载CSV并解析91个国家记录。
- GEM方法页面和worldsteel《World Steel in Figures 2026》在线版已归档。
- 下载地址、文件哈希见 `raw/download_manifest.json`；逐来源用途和数据年份见 `source_register.csv`。

已生成国家表和11地区聚合表。聚合按本项目EU27及其他地区词表进行；国家与世界合计已核对，未把来源表底部再次出现的China/Outside China汇总重复计入。

这些是来源中被追踪设施的容量，不是完整行业普查。GEM的门槛覆盖和季度有限更新仍需在基线覆盖率中披露。worldsteel的2026版年度产量、用钢和贸易主要对应2025年，不能改标签成为2026全年观测。当前日期为2026-11-16，全年2026流量尚未完成；年内统计、全年估计、2025历史校准和2027年后情景应分别标记。

资料：[GEM GIST](https://globalenergymonitor.org/projects/global-iron-steel-tracker)、[worldsteel 2026](https://worldsteel.org/data/world-steel-in-figures/world-steel-in-figures-2026/)。

## 三路线与未覆盖容量

`capacity_mapping_and_uncovered_pools.csv`保存了来源技术池、容量、产品单位、候选模型路线和尚缺的映射证据。

1. BOF钢容量是BF-BOF路线的候选输入，需要验证与高炉及外购铁水的联系、产能瓶颈和期初日期。
2. EAF不是废钢路线的同义词。来源中的EAF同时可能使用废钢、天然气/煤基DRI、HBI或铁水。没有原料或设施配对证据的EAF保留为待分配池，不自动归入SCRAP-EAF。
3. 绿色氢DRI是铁产品能力，不能直接当作等量H2-DRI-EAF粗钢能力，更不能在EAF能力之外重复相加。需要还原铁—钢收得率及下游EAF配对证据。
4. 天然气/煤基DRI、感应炉及其他/未知路线按用户选择不新增为内生路线，其覆盖缺口、供给和排放需单列。DRI与粗钢单位不同，不合计成一个“未覆盖粗钢能力”。

保留三路线意味着模型存在明确的覆盖边界。若仍使用全行业需求，必须以显式未覆盖供给项协调供需；或改用与三路线覆盖一致的需求边界。不能删除其他路线产能后仍要求三路线独自满足全部需求，也不能将缺失的其他供给默认为零。`inputs/uncovered_supply.csv`用于登记这一核算，尚未填值或选择具体校准方法。

## 需要补齐的初始化与情景输入

`inputs/`中各表目前只有表头，没有校准数值，缺失绝不表示零：

| 表 | 必需内容 |
|---|---|
| initial_state | 11地区×3路线的2026初始容量、剩余寿命、利用率及路线映射证据 |
| initial_reserves | 与开采口径一致的2026初始资源储量，不沿用原模型2022库存 |
| committed_projects | 2026年前实际承诺的投资管线，排除已计入初始库存的重复项目 |
| retirement_schedule | 2026—2043初始资产存续能力，观察值与情景区分 |
| annual_drivers | 2026基线/估计及2027—2043需求、资源供应、能源和原产国碳价情景 |
| annual_policy | 2026—2043免费配额、基准、修正和碳价，法规规定路径与预测价格分别记录 |
| technical_parameters | 工艺投入、成本、运维、寿命、排放、运输等，以及货币价格基年 |
| route_mapping | 来源设施/容量池到三路线的分配、产品转换与去重证据 |
| uncovered_supply | 未覆盖路线供给和排放，以及需求边界的协调方法 |

worldsteel的成品钢表观消费不能未经转换直接充当tCS粗钢需求；参数表应保存原商品口径和粗钢当量转换依据。容量、产量、铁产品与钢产品单位同样要分开。

未来需求、氢价、电价与碳价不是“实际数据”。应明确基准、高需求、低需求等情景和出处；不能把原论文的2026预测行称为实际2026基线，也不能把2035末值默默复制到2043年。

## 原代码需要改动的范围

原修正版在model.py将生产长度限制为14年，以2022为索引原点；PETS和PCM仅覆盖2022—2038；旧产能Xin至2041；排放基准与电网修正仅分段到2035。生产扩展至2040时，末次投资前瞻需要2043，现有向量会越界或缺少依据。

真正的2026重建需要让日历年、政策年、年龄和投资滞后分离，并改造输入、库存初始化、投资上界、原料约束、输出、绘图和测试。当前新增的 `replication_johnson2026_2040` 提供日历、已下载证据整理和输入预检；尚未把缺失的校准数据接入新的优化求解器，没有生成新期间的结果。

## 已执行的核验

- 日历检查：15个生产年度，18个参数年度，2026决策对应2029投运，2040对应2043。投资日历由 `case_config.json` 派生，预检会核对日历文件与配置一致；修改起止年或建设期后重跑 `prepare_inputs` 会同步再生成。
- 来源检查：kt/年转换到t/年；不混加铁和钢；国家合计与发布世界合计一致；汇总行不重复；NaN、负容量和重复国家行在解析阶段直接报错。
- 缺失检查：空表或缺失文件会给出 `input_ready=false`，不会填零、调用旧结果或宣称新模型已验证。`committed_projects.csv` 已进入预检：审核标记必须是布尔值，标记已核实而项目表缺失会报错；核实后确认无项目时允许空表。
- 数值与键检查：数值必须有限并在业务范围内（利用率、免费配额比例、路线分配比例限于0—1）；地区—路线、情景—地区（—路线）—年度、项目ID等业务键不得重复；同一产能池的分配比例合计必须为1；缺列、短行会定位到具体行列。
- 覆盖检查：年度表按情景逐组核对全地区（及路线）×2026—2043覆盖；只填单一地区凑齐年份、或用多个情景互补拼年份，均无法通过。

这12项准备测试通过，只证明上述准备功能。当前预检未通过：33个地区—路线初始状态以及其他校准输入尚缺，项目管线尚未复核，9月快照尚未重建至期初。状态见 `input_readiness.json`。

复跑准备与检查（在 `code/` 目录下执行）：

```powershell
python -m replication_johnson2026_2040.prepare_inputs
python -m replication_johnson2026_2040.check_readiness
python -m unittest discover -s replication_johnson2026_2040/tests -v
```

预检当前返回退出码2，表示输入尚未就绪，这是预期的诚实失败状态。`check_readiness`只是基础准备检查，不替代完整的输入校验、物理守恒或政策验证。
